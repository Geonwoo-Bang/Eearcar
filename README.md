# 이어카 (Eearcar)

Pleos Connect 기반으로 차주가 저장한 차량 이용정보를 조회하고 Gleo 음성으로 안내하는 앱입니다.

## 현재 구현 상태

- 차주 정보 저장 및 조회
- 충전카드 위치, 반납 정보, 전달사항의 Gleo 음성 안내
- 앱 내 질문 및 조회 결과 기록 표시
- 국내 2026년형 아이오닉 5 공식 사용설명서 연결

차주 정보 음성 안내와 기록 표시는 Pleos Connect 에뮬레이터에서 동작을 확인했습니다.

설명서 검색 결과의 Gleo 음성 답변 연동과 차량 사양·옵션에 따른 안내 구분은 추가 개발·검증 단계입니다.
차량 이용 종료 시 질문·조회 기록을 삭제하는 기능은 향후 구현할 계획입니다.

## 테스트 환경

- Pleos Connect Emulator v2.1.0
- Android 14 / API 34
- 화면 해상도: 2560 × 1440 px
- 개발 환경: macOS, Android Studio
- 패키지명: com.example.eearcar
- 앱 버전: 1.0

## 설치 및 실행 방법

1. 위 링크에서 APK 파일을 다운로드합니다.
2. Pleos Connect v2.1.0 에뮬레이터를 실행합니다.
3. 다운로드한 APK를 에뮬레이터 화면으로 드래그하여 설치합니다.
4. 앱 목록에서 ‘이어카’를 실행합니다.
5. 앱 화면에서 충전카드, 차주 메모, 반납 안내를 확인합니다.

기존에 다른 서명으로 설치한 동일 패키지의 앱이 있으면 설치가 실패할 수 있습니다.
이 경우 기존 앱을 삭제한 뒤 설치해야 하며, 삭제 시 기존 앱의 저장 데이터도 삭제됩니다.

## Gleo 음성 안내 테스트

에뮬레이터의 Gleo를 사용할 수 있는 상태에서 테스트합니다.
음성 입력을 위해 Mac의 마이크 접근 권한과 에뮬레이터의 마이크 입력 설정을 확인합니다.

다음과 같이 앱 이름을 포함해 질문합니다.

- “이어카 앱에서 충전카드 위치 알려줘.”
- “이어카 앱에서 반납 시간 알려줘.”
- “이어카 앱에서 반납 장소 알려줘.”
- “이어카 앱에서 차주 전달사항 알려줘.”

차주 저장정보에 맞는 음성 답변이 나오는지 확인하고,
이어카 화면에 질문과 조회 결과가 기록되는지 확인합니다.

시연용 정보 예시:
- 충전카드 위치: 조수석 앞 글로브박스
- 반납 시간: 18:00
- 반납 장소: 처음 차량을 받은 주차장
- 차주 전달사항: 차량 안에서는 금연해 주세요.

위 정보는 시연용이며 실제 예약·반납 정보가 아닙니다.

## 소스 코드 실행

1. 저장소를 다운로드하거나 복제합니다.
2. Android Studio에서 저장소 최상위 폴더를 엽니다.
3. 프로젝트에 지정된 Android SDK 및 Gradle 의존성을 설치하고 동기화합니다.
4. Pleos Connect 에뮬레이터를 실행한 후 app 모듈을 실행합니다.

프로젝트 설정:
- compileSdk / targetSdk: 37
- minSdk: 28
- Android Gradle Plugin: 9.5.0
- Gradle Wrapper: 9.6.0
- Kotlin Compose 플러그인: 2.2.10

제출용 APK의 서명 키와 비밀번호는 저장소에 포함하지 않습니다.

## 주요 파일

- app/src/main/java/com/example/eearcar/: 앱 소스 코드
- app/src/main/assets/schema.json: Gleo 호출 기능 및 입력값 정의
- app/src/main/assets/ioniq5kr/: 앱에 연결한 설명서 자료
- apk/: 제출용 release APK

설명서 자료의 권리는 해당 권리자에게 있습니다.
