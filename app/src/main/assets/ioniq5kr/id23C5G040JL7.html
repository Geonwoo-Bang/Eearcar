운전석 자세 메모리 초기화하기

운전석 자세 메모리 기능이 정상적으로 작동하지 않는 경우 다음과 같이 시스템을 초기화하십시오.

운전석이 원활하게 움직일 수 있도록 초기화를 진행하기 전에 주변의 장애물을 제거하십시오.

  1. 차량의 시동이 'ON'일 때 'P'(주차) 로 변속하고 운전석 도어를 여십시오.

  2. 운전석 조절 스위치를 이용해 좌석을 최대한 앞으로 당기고 등받이도 최대한 앞으로 젖히십시오.

  3. 1번 메모리 버튼과 운전석 전방 이동 스위치를 동시에 2초 동안 누르십시오.

  4. 경고음이 울리면 스위치에서 손을 떼십시오.

    • 경고음과 함께 좌석이 자동으로 움직이며 초기화가 진행됩니다.

  5. 경고음이 울리며 초기화가 끝나면 좌석을 조절한 후 메모리 버튼에 저장하십시오.

  • 다음과 같은 경우 시스템 초기화가 중단되고 경고음이 멈춥니다.

    • 운전석 자세 메모리 시스템 버튼을 누르는 경우

    • 운전석 조절 스위치를 누르는 경우

    • 차량이 3 km/h 이상의 속도로 움직이는 경우

    • 운전석 도어를 닫은 경우

  • 초기화 도중 경보음이 꺼지고 운전석이 멈추는 경우 다시 한 번 초기화를 진행하십시오.
