스마트 테일게이트 작동 중지하기

스마트 테일게이트 작동을 중지하는 방법은 다음과 같습니다.

  • 스마트 키 감지/웰컴 경보 작동 중:

    • 감지 영역을 벗어나거나 등록된 모든 스마트 키에서 도어 잠금/잠금 해제 버튼, 테일게이트 작동 버튼 또는 비상 경보 버튼을 눌러 기능을 즉시 중단할 수 있습니다.

    • 스마트 키의 도어 잠금 해제 버튼으로 스마트 테일게이트 기능을 중지한 후에는 도어를 하나 이상 열었다 닫고 모든 도어를 잠글 때까지 기능이 작동하지 않습니다.

  • 스마트 키 미감지/웰컴 경보 미작동 중:

    • 스마트 키의 도어 잠금 해제 버튼을 누르는 경우 스마트 테일게이트 기능이 일시적으로 중지되며, 30초 안에 도어를 열지 않으면 다시 작동합니다.

    • 스마트 키의 도어 잠금 버튼, 비상 경보 버튼 또는 테일게이트 열림 버튼을 눌러 해당 기능을 작동할 수 있습니다.

비상시에 대비해 스마트 테일게이트 기능 작동을 중지하는 방법을 숙지하십시오.
